BRAINFORZE EA DASHBOARD — DEMO PREVIEW

หน้าใหม่: ea-dashboard.html

สิ่งที่ทำงานในเดโม:
- แสดง EA ตัวอย่าง 3 รายการและตัวเลขจำลอง
- ปุ่มเริ่ม/หยุดเปลี่ยนสถานะจำลองในเบราว์เซอร์
- ตั้งค่าบัญชี/สัญลักษณ์/Timeframe/ความเสี่ยงเพื่อบันทึกเป็นค่าทดสอบ
- ประวัติเหตุการณ์จำลองเก็บใน LocalStorage
- ส่งออกตาราง EA ตัวอย่างเป็น CSV
- รีเซ็ตข้อมูลตัวอย่าง

ข้อจำกัดสำคัญ:
- ไม่เชื่อมต่อ MT5 หรือบัญชีโบรกเกอร์จริง
- ไม่ส่งคำสั่งซื้อขายจริง
- ไม่คอมไพล์ MQL5 และไม่ยืนยันว่า EA คอมไพล์ผ่าน
- ตัวเลขกำไร/ขาดทุนและ Drawdown เป็นข้อมูลตัวอย่าง ไม่ใช่ผลทดสอบจริง
- ราคาหน้า Dashboard เป็นข้อเสนอ ยังไม่เปิดขาย/ชำระเงิน
- การใช้งานจริงต้องมี MT5 terminal/bridge ที่ปลอดภัย, backend, authentication, entitlement, logging และการทดสอบ Demo

วิธีติดตั้ง: Deploy ไฟล์ทั้งหมดใน ZIP นี้เป็นชุดเดียวไปยัง Netlify โดยสำรอง deploy ปัจจุบันก่อน
