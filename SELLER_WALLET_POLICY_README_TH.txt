BRAINFORZE Membership + Seller Wallet policy preview

สถานะ: DEMO ONLY — NOT PRODUCTION / NO REAL PAYMENTS

กติกาธุรกิจที่สะท้อนในรุ่นนี้:
1. FREE SELLER และสมาชิกทุกระดับรับผิดชอบค่าธรรมเนียม Payment Gateway ของธุรกรรมตนเองตามอัตราจริงและเงื่อนไขที่เปิดเผยล่วงหน้า
2. BRAINFORZE ไม่อุดหนุนค่าธรรมเนียมถอนเงิน จึงไม่มีโควตาจำนวนครั้งที่ได้รับการสนับสนุนค่าธรรมเนียม 3/6/10 ครั้ง
3. ราคาสมาชิก 299 / 599 / 1,290 บาทเป็นราคาเสนอเบื้องต้น ยังไม่เปิดขาย
4. ห้ามใช้ยอดตัวอย่างหรือประวัติ LocalStorage เป็นหลักฐานธุรกรรมจริง
5. ไม่มีบัญชีผู้ใช้ ระบบชำระเงิน webhook การโอนเงินจริง หรือฐานข้อมูลกลางใน ZIP นี้
6. ก่อนเปิดจริงต้องสร้าง backend + ฐานข้อมูล ledger + ตรวจสอบ payment webhook + reconciliation + authorization + refund/dispute handling + terms/privacy และทดสอบ end-to-end
7. ผู้ขายควรเห็นค่าธรรมเนียมจริงจากผู้ให้บริการก่อนยืนยันรายการ ห้ามถือว่าค่าธรรมเนียมตัวอย่างในหน้า Wallet เป็นอัตราจริง

วิธีเผยแพร่:
- ZIP นี้รวมไฟล์เว็บไซต์ static ที่มีอยู่ในชุดต้นทางและหน้า seller-wallet.html เพิ่มเติม
- สำรอง deploy ที่ใช้งานอยู่ก่อนทุกครั้ง
- แตก ZIP ก่อนอัปโหลดโฟลเดอร์ไฟล์เว็บไซต์ตามวิธีของ Netlify; อย่าอัปโหลด ZIP แบบ add-on เดี่ยวแทนทั้งเว็บ
