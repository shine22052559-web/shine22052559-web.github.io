[ ] ตรวจ EMA เร็วน้อยกว่า EMA ช้า
[ ] ตรวจขีดจำกัด Max Positions, Basket Loss และ Drawdown

C. Strategy Tester
[ ] ทดสอบทุก tick ตามข้อมูลที่มีอย่างน้อยหลายช่วงตลาด
[ ] ตรวจตลาดแนวโน้มขึ้น ลง และ Sideways
[ ] ตรวจช่วง Spread สูงและข้อมูล Indicator ไม่พร้อม
[ ] ตรวจ Buy/Sell signal จากแท่งปิดแล้ว
[ ] ตรวจ SL/TP, Basket TP/SL และ Trailing
[ ] ตรวจ hedging: Position ที่มี Symbol/Magic ต่างกันต้องไม่ถูกแก้หรือปิด
[ ] ตรวจว่าหยุดเพิ่มออเดอร์เมื่อ Risk Guard ทำงาน
[ ] ตรวจ log ของคำสั่งที่ถูกปฏิเสธ/ปิดไม่สำเร็จ

ข้อจำกัดที่ต้องทราบ:
- Dashboard ใช้ Comment บนกราฟเป็นต้นแบบ ไม่ใช่แผง UI ขั้นสูง
- Basket แบบราคาเฉลี่ยจะไม่ประเมินตะกร้าที่มีทั้ง Buy และ Sell พร้อมกันเป็นราคาเป้าหมายเดียว
- Risk Guard หยุดการเปิดออเดอร์ใหม่ ไม่รับประกันว่าจะปิดสถานะทันทีเมื่อขาดทุนเกินเกณฑ์
- ผลทดสอบย้อนหลังไม่รับประกันผลกำไรในอนาคต
