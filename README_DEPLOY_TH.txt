BRAINFORZE COMPLETE GOLD MARKETPLACE — DEPLOY GUIDE
====================================================

แพ็กเกจนี้ต่อยอดจากเว็บไซต์ BRAINFORZE เดิม ไม่ใช่ภาพ mockup อย่างเดียว

สิ่งที่รวม:
- หน้าแรกปรับธีม Cyber-Luxury Black & Gold ให้ใกล้ภาพอ้างอิง
- ร้านค้า store.html พร้อมค้นหา กรองหมวด กดชื่อ/ภาพเพื่อดูรายละเอียด และปุ่ม + เพิ่มลงตะกร้า
- ภาพสินค้า SVG แยก 500 ไฟล์ตาม SKU ใน assets/product-images/ (สินค้าแต่ละรายการมีภาพเฉพาะรายการ)
- CSS รองรับมือถือและแก้ overflow ของการ์ดสินค้า
- LINE OA support shortcut: https://lin.ee/NaVtUAY
- หน้า HTML เดิมและ Netlify functions ที่อยู่ในแพ็กเกจเดิม
- รายการแคตตาล็อก 500 รายการและคู่มือ

วิธี Deploy:
1. แตก ZIP
2. อัปโหลดเนื้อหาทั้งหมดในโฟลเดอร์นี้ไปยัง Netlify Manual Deploy โดย index.html ต้องอยู่ที่รากของ deploy
3. อย่าอัปโหลดเฉพาะ index.html หรือ store.html เพราะต้องใช้ styles.css, assets/ และ netlify/
4. หลัง Deploy ตรวจหน้าแรกบนมือถือ, store.html, กดดูสินค้า, เพิ่มตะกร้า และปุ่ม LINE OA

ข้อจำกัด:
- ภาพสินค้าเป็นภาพประกอบ SVG ที่สร้างตาม SKU/หมวดสินค้า ไม่ใช่ภาพถ่ายหรือ mockup ของไฟล์ส่งมอบจริง
- รายการแคตตาล็อกไม่ได้หมายความว่าสินค้าทุกชิ้นมีไฟล์ส่งมอบและผ่าน QA แล้ว
- ระบบชำระเงินจริง/ยืนยัน webhook/ปลดล็อกดาวน์โหลด และ compile/backtest EA ต้องทดสอบและเชื่อมระบบจริงแยกต่างหาก
- ZIP นี้ยังไม่ได้ Deploy เข้าบัญชี Netlify ของคุณจากแชตนี้
