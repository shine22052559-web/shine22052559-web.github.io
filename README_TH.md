# BRAINFORZE Cyberpunk Dark Gold MVP

## เปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` เพื่อดูหน้าแรก
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์เดียวกันไปยัง Netlify (manual deploy)
4. ห้ามอัปโหลดเฉพาะ index.html เพราะหน้าเว็บต้องใช้ styles.css และ app.js

## หน้าที่มี
index.html, services.html, portfolio.html, pricing.html, how-it-works.html, about.html, contact.html, start.html, studio.html, website.html, graphic.html, branding.html, marketing.html, ai-art.html, video.html, presentation.html, custom.html

## ฟังก์ชัน MVP
- หน้าแรก Dark Gold Cyberpunk
- หน้าบริการแยกตามประเภท
- หน้าแกลเลอรีแนวทาง concept
- หน้าแพ็กเกจราคาและขั้นตอนทำงาน
- Studio เปลี่ยนสีและข้อความ พร้อมดาวน์โหลด HTML concept
- แบบฟอร์มบรีฟดาวน์โหลดเป็น TXT

## ข้อจำกัด
- สถิติบนหน้าแรกเป็นข้อมูลตัวอย่าง ห้ามนำไปอ้างว่าเป็นสถิติจริง
- ภาพ artwork ใช้ CSS concept placeholder ไม่ใช่ภาพถ่ายหรือผลงานลูกค้าจริง
- ยังไม่มีสมาชิก ฐานข้อมูล ชำระเงิน หรือส่งบรีฟขึ้นเซิร์ฟเวอร์
- ตัวปรับแต่งยังไม่ใช่ drag-and-drop อิสระแบบ Figma
- ราคาเป็นราคาเริ่มต้นตัวอย่าง ต้องยืนยันก่อนขายจริง
- ตรวจสอบชื่อแบรนด์และเครื่องหมายการค้าก่อนใช้เชิงพาณิชย์


## สถานะสำคัญของเวอร์ชันนี้
- นี่คือเว็บเดโมแบบ static สำหรับตรวจหน้าตาและประสบการณ์ใช้งานเท่านั้น
- หน้า Studio ไม่ให้ดาวน์โหลด HTML concept โดยตรงในเวอร์ชันนี้
- ลิงก์สั่งงานยังเป็นเพียงแบบฟอร์มเดโม ไม่ได้บันทึกคำสั่งซื้อไปยังเซิร์ฟเวอร์
- ยังไม่มีระบบสมาชิก ฐานข้อมูล การชำระเงินจริง การตรวจสอบสลิป หรือการปล่อยไฟล์หลังชำระเงิน
- ห้ามใช้รับชำระเงินจริงหรือส่งไฟล์ที่มีมูลค่า จนกว่าจะสร้างและทดสอบ backend, authorization, payment verification และ private file delivery
- การซ่อนปุ่มในหน้าเว็บเพียงอย่างเดียวไม่ใช่ระบบป้องกันไฟล์อย่างปลอดภัย ไฟล์ต้นฉบับใน static site อาจเข้าถึงได้หากเผยแพร่ไว้ใน public hosting


## ระบบช่วยเหลือลูกค้า (Support Widget)
- มีปุ่มช่วยเหลือลอยบนหน้าเว็บทุกหน้า
- ตอบคำถามที่พบบ่อยด้วยกฎคำสำคัญ (ยังไม่ใช่ AI และยังไม่ส่งข้อความเข้าระบบแอดมิน)
- หากไม่พบคำตอบ ลูกค้าสามารถกดส่งต่อไป LINE ได้
- ก่อนเผยแพร่ ให้เปิด `support.js` แล้วตั้งค่า `LINE_SUPPORT_URL` เป็นลิงก์ LINE ส่วนตัวของเจ้าของเว็บแล้ว
- ปัจจุบันลิงก์เริ่มต้นเป็น `https://line.me/ti/p/UyMcBDRXWw` ตั้งค่าเป็นลิงก์ LINE ส่วนตัวของเจ้าของเว็บแล้ว
- ห้ามอ้างว่าระบบยืนยันการชำระเงิน รับออเดอร์ หรือส่งไฟล์อัตโนมัติแล้ว เพราะยังไม่มี backend


## FAQ ฉบับครอบคลุม
- ระบบช่วยเหลือรองรับคำถามเรื่องบริการแต่ละประเภท ราคา การขอใบเสนอราคา วิธีเริ่มงาน บรีฟ Studio/ทดลองออกแบบ พอร์ตโฟลิโอ กำหนดส่ง การแก้ไข การชำระเงินและสลิป การยกเลิก/คืนเงิน การส่งมอบ บัญชีลูกค้า การบันทึกงาน มือถือ ปัญหาการเปิดเว็บ ลิงก์ ความเป็นส่วนตัว และการติดต่อแอดมิน
- คำตอบเป็น FAQ ตามคำสำคัญ ไม่ใช่ AI และไม่มีการสร้าง ticket หรือแจ้งเตือนแอดมินอัตโนมัติ
- ชำระเงินจริง การตรวจสอบสลิป และการส่งไฟล์ยังต้องทำผ่านกระบวนการที่แอดมินยืนยัน ระบบเว็บเดโมยังไม่ทำสิ่งเหล่านี้อัตโนมัติ


## ปรับปรุง FAQ สำหรับมือถือ (รุ่นนี้)
- แถบคำถามด่วนจัดเป็นแถวเดียวและเลื่อนซ้าย/ขวาได้
- จำกัดความสูงหน้าต่าง Support และให้เลื่อนเนื้อหาคำตอบภายในหน้าต่าง
- คำตอบเป็นประโยคภาษาไทยที่อธิบายข้อจำกัดของเดโมอย่างตรงไปตรงมา
- FAQ ยังคงเป็นระบบจับคู่คำสำคัญแบบ rule-based ไม่ใช่ AI ที่เข้าใจทุกข้อความ และไม่ได้ส่งข้อความแจ้งเตือนแอดมินอัตโนมัติ


## อัปเดตเวอร์ชันคำขอจ้างงาน
- เพิ่มหน้า `order.html` สำหรับกรอกคำขอและดาวน์โหลดเอกสาร TXT
- ปุ่มส่งคำขอเป็นเดโมฝั่งอุปกรณ์ ยังไม่บันทึกลงฐานข้อมูลหรือส่งคำสั่งซื้ออัตโนมัติ
- ให้ลูกค้าติดต่อแอดมินทาง LINE เพื่อยืนยันขอบเขต ราคา และกำหนดส่ง
- ยังไม่มีระบบล็อกอิน การรับชำระเงินจริง หรือการส่งมอบไฟล์อัตโนมัติ


## ระบบรับคำขอออนไลน์ V2

หน้า order.html ใช้ Netlify Forms ชื่อ project-request พร้อม honeypot ลดสแปม และยังดาวน์โหลด TXT เป็นสำเนาได้ หลัง Deploy ให้ตรวจใน Netlify Dashboard > Forms ว่าพบฟอร์ม project-request และทดสอบส่งข้อมูลสมมติ หากไม่มีเมนู Forms หรือไม่พบรายการส่ง แสดงว่ายังไม่เปิดใช้งาน/ยังไม่รองรับการส่งใน deploy นี้ อย่าใช้ข้อมูลลูกค้าจริงจนกว่าจะทดสอบสำเร็จ การรับคำขอไม่ใช่ระบบชำระเงินและไม่ยืนยันงานอัตโนมัติ


## EA Builder เพิ่มเติม
- เปิด `ea-builder.html` เพื่อกรอกแนวคิดและพารามิเตอร์ แล้วสร้างไฟล์ซอร์ส MQL5 `.mq5` จากแม่แบบ Moving Average Crossover
- การสร้างไฟล์ในเบราว์เซอร์ไม่ใช่การ Compile; ต้อง Compile ด้วย MetaEditor และทดสอบบน MT5 Demo ก่อนนำไปใช้
- Dashboard และ Builder รุ่นนี้ยังไม่เชื่อมต่อ MT5 จริงหรือระบบชำระเงิน
