# BRAINFORZE AUTO-PILOT — ชุดเว็บพร้อมนำขึ้น Netlify

## สิ่งที่มีในชุดนี้
- หน้าเว็บไซต์ BRAINFORZE พร้อม ticker ข่าว/ประกาศและหน้า EA Builder
- แบบฟอร์มสั่งงานที่เชื่อม Netlify Functions และสร้าง Order ID
- ฐานข้อมูลคำสั่งซื้อ/ไฟล์/ช่องทางชำระเงินผ่าน Netlify Blobs
- หน้า Owner Admin ล็อกอิน ตั้งค่าชื่อบัญชี/เลขบัญชี/QR, ดูคำสั่งซื้อ, กำหนดยอด, ยืนยัน LINE/รับชำระ, อัปโหลดและลบไฟล์ส่งมอบ
- หน้าติดตามคำสั่งซื้อด้วย token และการดาวน์โหลดที่ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์
- สร้างไฟล์ landing page อัตโนมัติสำหรับคำสั่งซื้อประเภท website ตามขอบเขต template
- ส่งลิงก์ไฟล์ทางอีเมลผ่าน Gmail App Password (เมื่อตั้งค่า)
- LINE webhook เป็นตัวเลือก ไม่จำเป็นหากยืนยัน LINE ด้วยมือ

## ติดตั้งบน Netlify
1. แตก ZIP นี้ลงโฟลเดอร์บนคอมพิวเตอร์
2. อัปโหลดทั้งโฟลเดอร์ไปยัง Git repository แล้วเชื่อม repository นั้นกับ Netlify หรือใช้วิธี deploy ทั้งโฟลเดอร์ผ่าน Netlify CLI (ไม่ใช่อัปโหลดเฉพาะ index.html)
3. ตรวจว่า Netlify ใช้ Node.js รุ่น LTS ที่รองรับ ES modules
4. ใน Netlify Site configuration → Environment variables เพิ่ม:
   - `ADMIN_PASSWORD` = รหัสผ่านแอดมินที่เดายากและไม่ใช้ซ้ำที่อื่น
   - `SESSION_SECRET` = สุ่มอย่างน้อย 32 ตัวอักษร
   - `LINE_CONTACT_URL` = URL LINE ที่คุณต้องการใช้ติดต่อ
   - `GMAIL_USER` = Gmail สำหรับส่งอีเมล (ถ้าต้องการ)
   - `GMAIL_APP_PASSWORD` = Gmail App Password (ถ้าต้องการ)
   - สำหรับ LINE OA webhook เท่านั้น: `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN`, และ `LINE_OA_BASIC_ID` ตามที่ระบุใน BACKEND_SETUP_TH.md
5. สั่ง deploy ใหม่หลังตั้ง environment variables
6. เปิด `https://โดเมนของคุณ/owner-admin.html` แล้วเข้าสู่ระบบ ตั้งชื่อบัญชี/เลขบัญชี/QR ที่ถูกต้อง
7. ทำคำสั่งซื้อทดสอบมูลค่า 0 หรือทดสอบภายใน ห้ามใช้รายการเงินจริงเป็นครั้งแรก ตรวจตั้งแต่สร้างคำสั่งซื้อ → ยืนยัน LINE → แจ้งโอน → ยืนยันรับเงิน → ดาวน์โหลด/อีเมล ก่อนเปิดขายจริง

## ข้อจำกัดสำคัญ — อ่านก่อนรับเงินจริง
- นี่คือชุดเว็บและ backend สำหรับ Netlify; ไม่ได้หมายความว่าเว็บไซต์ถูก deploy เข้าโดเมนของคุณแล้ว
- ต้องตั้งค่า secrets, บัญชีรับเงิน, LINE และอีเมลด้วยตัวคุณเองก่อนใช้งานจริง ห้ามใส่ secrets ลงในไฟล์ HTML/JS หรือส่งมาในแชต
- การรับชำระในรุ่นนี้ **ยังเป็นการยืนยันโดยเจ้าของ** หลังตรวจยอดเงินจริง ไม่ได้เชื่อม API ธนาคารและไม่ตรวจสลิปอัตโนมัติ ดังนั้นยังไม่ใช่ระบบไร้คนดูแล 100%
- การยืนยัน LINE อัตโนมัติต้องตั้ง LINE Official Account Messaging API และ webhook; ถ้าไม่ตั้ง ใช้ยืนยันด้วยมือใน Owner Admin
- งานเว็บไซต์ที่สร้างอัตโนมัติเป็น landing-page template ตามข้อมูลลูกค้า ไม่ใช่การสร้างเว็บไซต์หลายหน้าระดับ production แบบไม่จำกัดโดย AI
- EA/กราฟิก/วิดีโอ ยังต้องมีไฟล์ส่งมอบที่สร้างและทดสอบแล้วอัปโหลดใน Owner Admin; EA ยังต้องผ่าน MetaEditor/Strategy Tester ตามข้อกำหนดงานก่อนส่ง
- ไฟล์ส่งมอบจำกัด 4 MB ต่อไฟล์ในรุ่นนี้
- ราคาใน `netlify/lib/shared.js` คือ EA 199 บาท, เว็บไซต์ 4,990 บาท, กราฟิก 1,490 บาท, วิดีโอ 2,990 บาท และประเภทอื่นราคา 0 เพื่อรอเจ้าของกำหนด หากนโยบายราคาใน Master Plan ยังขัดแย้ง ห้ามเปิดรับชำระจริงจนกว่าจะอนุมัติราคา
- ควรเพิ่ม rate limiting, privacy/terms, การสำรองข้อมูลและแผน incident response ก่อนใช้งานเชิงพาณิชย์เต็มรูปแบบ

## ทดสอบเบื้องต้นในเครื่อง
- `npm install`
- `node --check app.js` และ `node --check custom.js` (ตรวจ syntax เฉพาะไฟล์ JavaScript; ไม่ใช่การทดสอบ end-to-end)
- deploy preview แล้วทดสอบทุก flow ตาม checklist ใน `BACKEND_SETUP_TH.md`

ดูคู่มือตั้งค่ารายละเอียดเพิ่มเติมใน `BACKEND_SETUP_TH.md`.
