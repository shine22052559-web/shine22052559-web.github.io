# Quick Start — MT5 Expert Advisor

1. Install MetaTrader 5 from your broker.
2. Open File → Open Data Folder → MQL5 → Experts.
3. Copy the `.mq5` source there and compile in MetaEditor; use `.ex5` only when supplied.
4. Test in Strategy Tester first; do not start on a live account.
5. Attach to a chart, enable Algo Trading only after checking inputs.
6. Confirm symbol suffix, lot limits, stop levels, spread and trading hours.

Trading can lose money. A successful compile does not prove strategy quality.
